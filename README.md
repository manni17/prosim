# proSIM Engine

Professional Simulation Engine for Product Management Training.

## Quick Start

### 1. Prerequisites
- Python 3.12+
- Node.js 18+

### 2. Installation
Install both Backend and Frontend dependencies with one command:
```bash
npm run install:all
```

### 3. Run Development Environment
Launch the full stack (FastAPI + React) in a single terminal:
```bash
npm start
```
- **Backend:** http://localhost:8000
- **Frontend:** http://localhost:5173

## Project Structure
- `engine/`: Simulation logic and physics.
- `server/`: FastAPI integration layer.
- `client/`: React/Vite visual interface.
- `data/`: JSON scenarios and content.
- `docs/`: Strategic governance and changelogs.
- `tests/`: Pytest suite.
