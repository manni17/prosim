# UX-03: Progressive Data Interpolation

## Goal
Decouple simulation time (discrete turns) from render time (smooth experience) by interpolating metric changes over a fixed duration. This simulates "Real-Time Impact" and provides immediate visual feedback that persists after the turn is executed.

## Logic
1.  **State Separation:** Maintain a `displayValue` (rendered) separate from the `targetValue` (actual game state).
2.  **Interpolation Engine:** When `targetValue` changes:
    *   Calculate `delta = targetValue - startValue`.
    *   Duration: 15,000ms (15s).
    *   Tick Rate: 60fps (approx 16ms) or 100ms for performance.
    *   Update `displayValue` linearly or with easing.
3.  **Scope:**
    *   **MaxPanel:** Revenue and Traffic charts/KPI cards.
    *   **Taskbar/TopBar:** Health, Morale, Trust percentages.

## Implementation Strategy
- **Hook:** `useProgressiveValue(target, duration)`
- **Integration:** Wrap existing raw values in components with this hook.
- **Performance:** Ensure React re-renders are efficient (don't block the UI thread). Use `requestAnimationFrame` if possible, or `setInterval` for simplicity if sufficient.
