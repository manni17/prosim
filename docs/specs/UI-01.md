# UI-01: CLI Command Parser (Shell)

## Requirements
- **Framework:** Use `click` for command parsing and `rich` for terminal output.
- **Entry Point:** `main.py` acting as the `prosim` executable.
- **Commands:**
  - `status`: Displays current GameState (Health, Phase, Score) and the full History log.
  - `turn`: Executes a game turn.
    - Argument: `--type [work|rest]`
- **Output:**
  - Use Rich `Console` and `Table` or `Panel` to display state.
  - History should be shown as a chronological log.
- **Error Handling:** Graceful exit on invalid commands or logic errors.
