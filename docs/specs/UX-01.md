# UX-01: Immersive Feedback System

## Requirements
- **Goal:** Add immediate visual and behavioral feedback to user actions to increase immersion and clarity of consequences.
- **Features:**
  - **Toast Notifications:** Use `sonner` to display success/error messages after turns (e.g., "Revenue Increased", "Team Morale Dropping").
  - **Critical Alerts:** Visual screen flash or persistent border warning when metrics (Health, Trust, Morale) drop below 20%.
  - **State Comparison:** Logic in `App.jsx` to compare `oldState` and `newState` to determine which toasts to fire.
- **Visuals:**
  - Standard Toast positioning: Top Right.
  - Border Flash: Subtle red glow for damage, green for gains.

## DoD
- Toast appears instantly after clicking an action in Inbox or Chat.
- Desktop displays a red border when Health is low.
- `sonner` is integrated and functional.
