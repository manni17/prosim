# QA-01: Pytest Infrastructure

## Requirements
- **Goal:** Replace ad-hoc validation scripts with a standardized `pytest` test suite.
- **Framework:** `pytest` is the primary runner.
- **Structure:**
  - `tests/conftest.py`: Defines global fixtures (API Client, Game Session) to avoid code duplication.
  - `tests/unit/`: Logic-heavy tests (Math, State Transitions, RNG).
  - `tests/integration/`: End-to-end API tests (FastAPI -> Controller -> State).
- **Fixtures (`conftest.py`):**
  - `client`: Returns a `TestClient(app)` instance.
  - `session_id`: Automatically starts a new game and returns the `X-Session-ID`.
- **Standards:**
  - All new features MUST be tested via `pytest`.
  - Deprecate usage of `python tests/verify_*.py`.

## DoD
- `pytest` command runs successfully.
- `conftest.py` provides usable fixtures.
- Basic health check test passes.
