# WEB-20: Exit Interview & Detailed Feedback

## Goal
Replace generic failure text with a structured "Exit Interview" system that provides narrative context to the player's loss.

## Logic
1.  **State Tracking**: The `GameState` will tracks a `termination_details` dictionary.
2.  **Trigger**: When `_check_game_over` detects a lose condition (Health, Trust, Morale <= 0), it populates `termination_details`.
    *   **Trust <= 0**: "Gross Negligence" - Stakeholder revolt.
    *   **Health <= 0**: "Medical Leave" - Burnout.
    *   **Morale <= 0**: "Team Mutiny" - Mass resignation.
    *   **Revenue Failure**: "Insolvency" - Bankruptcy.

## UI (ReportCard.tsx)
The Game Over screen transforms into an "HR Termination Form".
-   **Header**: "NOTICE OF TERMINATION" (Official/Legal aesthetic).
-   **Cause**: Red text highlighting the primary failure reason.
-   **Notes**: Specific narrative feedback generated by the backend.
-   **Performance**: Retain the existing charts but frame them as "Audit Logs".
