# Design System Tokens

## Glass Materials
- **Glass Window**: `0 0% 100% / 0.6`
- **Glass Dock**: `0 0% 100% / 0.3`
- **Glass Sidebar**: `0 0% 100% / 0.2`
- **Glass Card**: `0 0% 100% / 0.5`
- **Glass Hover**: `0 0% 100% / 0.8`

## Glass Borders
- **Glass Border Strong**: `0 0% 100% / 0.4`
- **Glass Border Subtle**: `0 0% 100% / 0.2`

## Rules
- **DO NOT** use Slate-900 or any solid dark backgrounds for windows/cards.
- **ALWAYS** use `backdrop-blur` with the appropriate glass variable.
- **ALWAYS** use the glass variables defined above for backgrounds and borders.
